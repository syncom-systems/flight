# Security policy

Report a suspected vulnerability privately through this repository's "Report a vulnerability" button (Security tab, private vulnerability reporting). Please do not open a public issue for it. Include the Flight version (`flight --version`), the operating system, and steps to reproduce.

What Flight promises about security, and what it does not, is in `docs/releases/v1.0-contract.md` section 6. Only the latest release receives fixes.

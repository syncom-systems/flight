## Known limits of 1.1.0

- Codex continuation after a restart is not offered (ADR-010); Codex is verified with a real CLI only on macOS arm64, one version.
- Setup installs only what it can do with a package manager the person already has; Homebrew itself, agent logins and anything on a remote node are never touched.
- Setup asks questions only on a terminal. In scripts and services nothing changes.
- The selected row on Apple Terminal is hard to read (#111, post-v1).

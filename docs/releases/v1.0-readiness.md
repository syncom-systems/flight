# Flight v1.0 readiness matrix

Authoritative record of what is verified for v1.0.0 (contract: `v1.0-contract.md`; work: milestone `v1.0.0`). Status is PASS only with evidence named here; green development CI alone is not release qualification, so areas that must be shown on the release candidate's own artifacts stay NOT VERIFIED until they are. "Blocking" means the owner's GO needs PASS (or NOT APPLICABLE with a reason).

Last updated: 2026-10-11, before any candidate exists.
